# Скиллы Matt Pocock правим на месте, апстрим переносим вручную

Процесс Шаблона (стоп-гейты, разделение Handoff и Close-task, протокол Оркестратора) расходится с исходными скиллами Matt Pocock. Когда наше поведение задавалось в AGENTS.md поверх нетронутых скиллов, агент получал два противоречащих текста. Поэтому правим скиллы на месте, а в Реестре отмечаем источник каждого: `matt`, `matt+правки` или `свой`. Обновления из апстрима переносим вручную по diff. `npx skills update` вслепую не запускаем: он затрёт правки.

## Considered Options

- **Не трогать оригиналы, расхождения держать в AGENTS.md или в скиллах-обёртках.** Отклонено: именно так появились противоречия, найденные при аудите.
- **Полный форк без отслеживания апстрима.** Отклонено: улучшения Matt полезны, и колонка «источник» показывает, что сверять при обновлении.

# Корень репозитория — это Шаблон; Метадокументы удаляет `/init-project`

Шаблон развивается по тому же процессу, который он поставляет: интервью, спеки, ADR, handoff. Чтобы скиллы работали и при разработке самого Шаблона, корень репозитория и есть содержимое Шаблона. Метадокументы (спеки, ADR и handoff о развитии Шаблона) лежат в обычных `docs/...`. При создании Проекта их очищает `/init-project`: он же сбрасывает глоссарий и `LATEST.md` в пустой каркас.

## Considered Options

- **Подпапка `template/` с содержимым, корень — репозиторий разработки.** Отклонено: скиллы Шаблона не активны, пока мы над ним работаем, и процесс нельзя проверить на себе.
- **Отдельная папка `meta/` для Метадокументов.** Отклонено: скиллы `to-spec`, `handoff` и `domain-modeling` пишут в стандартные `docs/...`. Пришлось бы переопределять пути только для Шаблона.

## Consequences

- Метадокументы, которые нужно очистить, перечисляются в одном месте: в манифесте `/init-project`. Новая папка с документами о Шаблоне должна попасть в этот список.
- Обоснования решений (эти ADR) в Проект не переносятся. Проект ссылается на репозиторий Шаблона.

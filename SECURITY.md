# Security Policy

## Supported Versions

Only the latest MAJOR version of this template receives security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

When a new major version is released, the previous major version is deprecated and is no longer maintained for security patches.

---

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability or vulnerability in the template scripts, automation tools, or skills, please report it responsibly.

### Preferred Method: GitHub Private Vulnerability Reporting

Please report security issues using GitHub's **Private Vulnerability Reporting**:

1. Navigate to the repository's **Security** tab on GitHub:
   `https://github.com/cannoneer85-svg/StrataHarness/security/advisories/new`
2. Click **Report a vulnerability**.
3. Fill out the report form with details of the vulnerability, reproduction steps, and impact.

This allows us to collaborate on a fix and publish an advisory privately before publicly disclosing the issue.

### Alternative / Fallback Contact

If GitHub Private Vulnerability Reporting is unavailable, you may email the maintainer directly at:
- **Email:** `cannoneer85@yandex.ru`
- **Subject:** `[SECURITY] StrataHarness vulnerability report`

Please do **NOT** file public GitHub issues or discussions for security vulnerabilities.

---

## Response Process

- **Acknowledgement:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will verify and assess the severity of the report within 5 business days.
- **Coordination & Release:** If confirmed, we will coordinate a fix, release a security patch, and publish an advisory giving credit to the reporter (unless anonymity is requested).

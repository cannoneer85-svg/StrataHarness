# Шаблон проекта (StrataHarness)

Стартовый сетап, из которого создаются новые проекты: правила агентов, скиллы, процесс работы и каркас документации. В этом репозитории разрабатывается только сам сетап.

> Этот глоссарий описывает развитие Шаблона. При создании Проекта `/init-project` заменяет его пустым каркасом.

## Language

### Шаблон и проекты

**Шаблон**:
Этот репозиторий — стартовый сетап, из которого создаются Проекты.
_Avoid_: boilerplate, стартер, сетап-проект

**Проект**:
Репозиторий, созданный из Шаблона и прошедший инициализацию.
_Avoid_: дочерний проект, инстанс

**Метадокументы Шаблона**:
Спеки, ADR и handoff-документы о развитии самого Шаблона. В Проект не переносятся.
_Avoid_: служебные доки

### Маршрутизация задач

**Шаг 0**:
Определение Типа задачи и Категории до начала любой работы. Агент предлагает, пользователь подтверждает.
_Avoid_: триаж (это отдельный процесс для входящих issue)

**Тип задачи**:
Задача разработки (меняет код) или Задача анализа (аналитика, исследование, документ). От типа зависит, какой флоу применяется.

**Категория**:
Оценка масштаба Задачи разработки: Minor, Feature или Epic. Определяет число раундов интервью и обязательные этапы. Может уточняться по ходу интервью.
_Avoid_: сложность, T-shirt size

**Туман**:
Состояние задачи, при котором путь к результату не виден и не укладывается в одну сессию. Ведёт в `/wayfinder`, а не в интервью.

### Процесс

**Цикл разработки**:
Шестиэтапный путь Задачи разработки: интервью → спецификация → тикеты → реализация → ревью → закрытие.

**Стоп-гейт**:
Обязательная остановка в конце этапа: дальше только после явного подтверждения пользователя.

**Handoff**:
Перенос контекста в новую сессию: документ передачи, обновление `LATEST.md`, очистка завершённого из `.scratch`. Не коммитит.
_Avoid_: закрытие задачи

**Close-task**:
Закрытие задачи: всё, что делает Handoff, плюс коммит. Запускается только по команде пользователя.
_Avoid_: handoff, ship, finish

**Реестр скиллов**:
Актуальный список активных скиллов Шаблона с разбивкой по категориям.

### Версии и релизы

**Версия Шаблона**:
Номер SemVer (`vMAJOR.MINOR.PATCH`) в файле `VERSION` и git-теге. В Проекте записывается как `template-version` в Реестре скиллов. MAJOR — изменение, ломающее `-Mode Update` у существующих Проектов.
_Avoid_: ревизия, билд

**Релиз**:
Зафиксированная Версия Шаблона: релизный коммит с обновлёнными `VERSION` и `CHANGELOG.md` плюс тег. Создаётся локально через `/release`; после подтверждения на стоп-гейте скрипт делает релизный коммит, аннотированный тег и пушит в `main`; публикацию GitHub Release по тегу выполняет GitHub Action. Единственное исключение из запрета на push для агента; force-push запрещён всегда.
_Avoid_: деплой, выкладка

### Исполнение

**Оркестратор**:
Главный агент в стратегии последовательных субагентов. Распределяет тикеты и проверяет результат, сам код не пишет.

**Бриф**:
Самодостаточный промпт, с которым запускается субагент: он не видит основного диалога.
